Supersedure Studio is a fork of [Beekeeper Studio](https://github.com/beekeeper-studio/beekeeper-studio) with all of the commercial-licensed code removed. Everything in
[the repository](https://github.com/thePeras/supersedure-studio) is available under the
GPLv3 license, which keeps all forks open source too.

You can download it on the
[GitHub releases page](https://github.com/thePeras/supersedure-studio/releases/latest).
