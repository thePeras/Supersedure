## Simply Download And Run


Download and run the Windows installer from [our website](https://supersedurestudio.io).

Currently Supersedure Studio only supports the `x86_64` architecture. Support for `ARM64` will come in a future release.


## Portable Version of Supersedure Studio

We also have a portable version of Supersedure Studio that does not require installation. This is also available from our website.
